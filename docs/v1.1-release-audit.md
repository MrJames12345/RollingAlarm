## Complete Catalog of Defects Fixed

### A. Android Native, Gradle, R8, Manifest & Localization (`@native-build`)
1. **Git Remote & Stale Docs (`origin`, `docs/logo-design-brief.md:105`):** Updated `origin` from `CarsonAlarm` to `https://github.com/MrJames12345/RollingAlarm.git`; updated `com.example.rolling_alarm` -> `com.casellaweb.rolling_alarm`.
2. **Android 16, NDK r28+ & R8 Hardening (`android/app/build.gradle.kts`, `android/app/proguard-rules.pro`, `android/app/src/main/res/raw/keep.xml`):**
   - Pinned `ndkVersion = "28.2.13676358"` and `targetSdk = maxOf(flutter.targetSdkVersion, 36)`.
   - Enabled `isMinifyEnabled = true`, `isShrinkResources = true`, and wired `proguard-rules.pro` in `buildTypes.release`.
   - Added comprehensive R8 keep rules for `com.dexterous.flutterlocalnotifications.**`, Gson `TypeToken` + generic signatures (`InnerClasses, Signature, *Annotation*, EnclosingMethod`), `org.xmlpull.**`, RevenueCat (`com.revenuecat.purchases.**`), Play Billing (`com.android.billingclient.api.**`), Jetpack Glance/DataStore/`home_widget`, `android_alarm_manager_plus`, and all 14 `com.casellaweb.rolling_alarm.*` native classes.
   - Created `res/raw/keep.xml` (`tools:keep="@mipmap/ic_launcher,@drawable/*,@raw/*,@xml/alarm_widget_info"`).
3. **Defensive Permission Stripping (`android/app/src/main/AndroidManifest.xml:1-19`):** Added `xmlns:tools` and `tools:node="remove"` for `AD_ID`, `READ_MEDIA_AUDIO`, `READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`, and `FOREGROUND_SERVICE_SPECIAL_USE`.
4. **CRITICAL — Widget Dismissal Timestamp Bug (`WidgetRoutineBridge.kt:134-137, 164-171, 197-219`):**
   - Fixed `toDriftTimestamp` from `epochMillis * 1000L` (microseconds) to `epochMillis / 1000L` (Drift Unix seconds), which had caused widget dismissal counts to always read `0`.
   - Replaced shared mutable static `SimpleDateFormat` with thread-safe per-call `SimpleDateFormat("hh:mm a", Locale.getDefault())`.
   - Added `app_flutter/rolling_alarm.db` fallback path matching `AlarmSqliteGate.kt`.
   - Stepped `PRAGMA busy_timeout = 5000` cursor via `.use { it.moveToFirst() }` so Android SQLite actually executes the pragma.
5. **Native Fire-Time Gate & Boot Resurrection Split (`AlarmSqliteGate.kt`, `AlarmResurrectionReceiver.kt:56`):**
   - Added stepped `PRAGMA busy_timeout = 5000`, DST-safe disabled-weekday check, and daily-cap check (including `extra_max_times_today`) for fresh cycles (`current_snooze_count == 0`) while allowing snooze resumes (`current_snooze_count > 0`).
   - Added `shouldSuppressResurrection()` (structural checks only: missing/deleted/inactive/muted) for `AlarmResurrectionReceiver` so boot resurrection never drops future parked alarms.
6. **False Ringing Flag on Upcoming Alarm Clock Tap (`AlarmUiSchedulerPlugin.kt:180-190`):** Removed `putExtra(MainActivity.EXTRA_ALARM_RINGING, true)` from `AlarmClockInfo.showIntent` so tapping the status-bar clock icon before an alarm fires never falsely sets `ra_is_ringing`.
7. **Android 8+ FGS Contract Guard (`AlarmRingingService.kt:61-72, 567`):** Guarded `AlarmRingingService.start` against `routineId < 0` and ensured `startForegroundWithType` runs before `cancelNotificationAndStop` if an invalid intent arrives directly.
8. **Android 16 Edge-to-Edge & 10-Locale Widget Strings (`WidgetConfigActivity.kt:238-336`, `res/values-{ar,de,es,fr,hi,ja,ko,pt-rBR,ru}/strings.xml`):**
   - Wrapped `WidgetConfigActivity.buildUi()` in an outer `FrameLayout` carrying `fitsSystemWindows = true` so system-bar insets do not overwrite inner `20dp`/`28dp` padding.
   - Added localized `widget_pro_title`, `widget_pro_message`, `widget_pro_unlock`, and `widget_pro_cancel` across all 9 non-English locales.
9. **Patrol Instrumentation UTF-8 BOM Fix (`android/app/src/androidTest/java/com/casellaweb/rolling_alarm/MainActivityTest.java:1`):** Stripped leading UTF-8 BOM (`0xEF 0xBB 0xBF`) that caused `javac` to fail compiling Patrol instrumentation tests (`illegal character: '\ufeff'`).

### B. Alarm Engine, DST Math, Drift v18 & Isolate PDF (`@engine-data`)
10. **CRITICAL R8 AOT RELEASE BLOCKER — Missing `@pragma('vm:entry-point')` (`lib/services/alarm.dart:21-34, 166, 431`):**
    - Caught live in R8 Release APK Test B: Dart AOT failed native lookup of `RA_AlarmService._alarmCallback` / `_watchdogCallback` because enclosing `class RA_AlarmService` was not annotated with `@pragma('vm:entry-point')`, breaking all background alarm & watchdog callbacks in release builds.
    - Fixed by annotating `class RA_AlarmService` with `@pragma('vm:entry-point')` (preserving persisted upgrade handles) and adding top-level `@pragma('vm:entry-point')` entrypoints `raAlarmBackgroundCallback` and `raWatchdogBackgroundCallback` passed to `AndroidAlarmManager.oneShotAt`.
11. **CRITICAL — `ExtraMaxTimesToday` & Daily-Cap State Integrity (`lib/services/alarm.dart`, `lib/services/daily_ring_limit.dart`, `lib/pages/routine_edit.dart`):**
    - Passed `extraMaxTimesToday: state.ExtraMaxTimesToday` in `_alarmCallback` (fixing silently suppressed Pro "Adjust Today's Max" rings).
    - Fixed `setTodayMaxCount` to park on `nextCalendarDayStart` + `deferToEnabledDay` when lowering cap at/below count, write `TimesRingToday: Value(priorCount)` alongside `TimesRingDay: Value(period)`, anchor unparking to `pausedAt ?? now`, clamp interval `< 1`, and never arm OS timers when paused.
    - Fixed stale `ExtraMaxTimesToday` rollover resurrection across day boundaries in `_handleMutedFire`, `nextTriggerForAction`, `handleTransition`, and `resetTodayCounter`.
    - Passed `effectiveExtra` through `resetTodayCounter`, `retargetNextAfterCounterReset`, and `retargetNextAfterEdit`, and guarded `routine_edit.dart` + `resetTodayCounter` from arming paused routines.
    - Fixed `retargetNextAfterEdit` to stay on `nextCalendarDayStart` when editing Day Start while already capped before today's Day Start.
12. **Concurrency, Clamping & Local-Time Normalization (`alarm.dart`, `database.dart`, `daily_ring_limit.dart`, `weekday_schedule.dart`, `pdf.dart`, `widget.dart`):**
    - Added `PausedAt != null` early-return guard and `matchNextTriggerTime` CAS on `_alarmCallback` weekday/cap deferrals.
    - Clamped `< 1` intervals/snoozes to `60s` across `RA_DailyRingLimit` helpers, `_scheduleWatchdog`, and `setTodayMaxCount`.
    - Added `RA_Database.getRoutineByIdOrNull` so `recoverRoutine` no-ops cleanly on missing IDs instead of throwing `StateError`.
    - Normalized UTC `DateTime` inputs via `.toLocal()` in `periodStart`, `nextCalendarDayStart`, `isDateEnabled`, `RA_PdfService.shareLogsPdf`, and `RA_WidgetService.updateWidgetState`.
